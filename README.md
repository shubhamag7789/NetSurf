# NetSurf — Adaptive Agentic Browser for Intelligent Web Task Automation

> Autonomous, agentic web browser co-pilot implemented as a Google Chrome Extension (Manifest V3) coupled with reasoning brain and deterministic recommendation algorithms.

## Project Vision
NetSurf operates directly inside the browser environment, performing the Observe -> Reason -> Act -> Verify -> Recover loop on the active web page without remote headless browser costs or anti-bot blocks.

## Core Pillars
- **Chrome Extension (Manifest V3)**: Native browser execution, DOM indexing, visual action execution.
- **Side Panel Interface**: Human-in-the-loop interaction, step streaming, profile vault.
- **Agentic Automation**: Semantic autofill, web search, price comparison, structured data extraction.
